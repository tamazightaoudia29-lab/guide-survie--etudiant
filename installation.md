# 📥 Guide d'Installation & Déploiement

Ce guide explique comment cloner, modifier et déployer le projet sur GitHub Pages.

---

## 📋 Prérequis
* Un compte GitHub.
* Un navigateur web et un éditeur de code (ou l'environnement de développement intégré de ton Chromebook).

---
